# SOP SEO Etsy (Marketing)

Sumber: ringkasan `marketing-seo-specialist` dari [msitarzewski/agency-agents](https://github.com/msitarzewski/agency-agents) (MIT). File lengkap: `REFERENCE-seo-specialist.md` — baca HANYA bila butuh detail audit teknis web (sebagian besar tidak relevan untuk Etsy; yang dipakai bagian keyword + on-page + anti-kanibalisasi).

Kapan dipakai: bikin/audit listing Etsy digital planner.

## Aturan wajib per listing

1. **Judul front-load**: keyword utama di 40 char pertama. Format: `[Keyword Utama] — [Modifier/Audience] | [Bonus]`. Maks 140 char.
2. **13 tags habis**, tidak boleh kosong. Campuran: 4 tag keyword utama + 6 long-tail + 3 musiman/audience. Jangan duplikat kata yang sudah ada di judul (Etsy menghitung keduanya).
3. **160 char pertama deskripsi** = jualan (apa yang didapat + untuk siapa + format file). Search engine memotong di situ.
4. **Alt-text semua foto**: deskripsikan isi gambar + keyword natural, bukan "image1.png".
5. **Anti-kanibalisasi (WAJIB sebelum publish listing baru)**: 1 keyword utama = 1 listing saja. Cek keyword-bank + listing existing; jika 2 listing memperebutkan keyword yang sama, tentukan owner dan beri listing lain long-tail berbeda.

## Checklist audit listing existing

- [ ] Judul depan mengandung keyword target?
- [ ] 13 tags terisi & tidak duplikat judul?
- [ ] 160 char pertama deskripsi menjual?
- [ ] Alt-text terisi semua foto?
- [ ] Keyword utama tidak dikuasai listing lain?
