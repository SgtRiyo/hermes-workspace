# SOP TikTok / Reels (Marketing)

Sumber: ringkasan `marketing-tiktok-strategist` dari [msitarzewski/agency-agents](https://github.com/msitarzewski/agency-agents) (MIT). File lengkap: `REFERENCE-tiktok-strategist.md`.

Kapan dipakai: bikin script/kalender konten pendukung listing Etsy digital planner.

## Aturan konten

1. **Hook 3 detik pertama** — teks besar + pernyataan provokatif/nyata. Tanpa hook, video mati.
2. **Mix pillar 40/30/20/10**: edukasi (cara pakai planner) / hiburan (relatable creator) / inspirasi (hasil before-after) / promosi (CTA Etsy). Tidak boleh 100% promosi.
3. **Hashtag 5-8**: campuran 2 besar (#tiktokshop, #digitalplanner), 3 niche (#contentcalendar #etsyseller), 1-2 branded.
4. **Format vertikal mobile-first**, durasi 15-30 detik, completion rate target ≥70% → potong semua bagian lambat.
5. **Cross-post**: 1 video TikTok → Reels + Shorts dengan caption beda, jangan copy-paste mentah.

## Struktur script 4 bagian

| Detik | Isi |
|---|---|
| 0-3 | Hook: masalah/klaim berani |
| 3-15 | Demo produk: screen-record flip planner, tunjukkan 2-3 halaman |
| 15-25 | Bukti/manfaat: "hemat 3 jam/minggu merencanakan konten" |
| 25-30 | CTA tunggal: "Link di bio / cek toko kami" |

## Target ukur (laporkan jujur, tanpa karangan)

- ER ≥ 8% (industry avg 5.96%), completion ≥ 70%, CTA click rate kira-kira 1-2%.
- Data belum ada = tulis "belum ada data", isi setelah rekap mingguan pertama.
