# Aturan Pencatatan (3 aturan inti)

Rangkuman dari `../../TEAM_SOP.md` bagian "Aturan pencatatan wajib". Dicatat 2026-09-15 oleh Lead.

1. **Setiap fakta berakhir jadi file.** Pesan berisi fakta klien/order/deadline/nominal/keputusan WAJIB ditulis ke `obsidian/klien/<nama>.md`, `obsidian/proyek/<nama>.md`, atau `obsidian/sop/<topik>.md` — memori bawaan hanya tambahan, bukan pengganti.
2. **Append, jangan timpa.** Dilarang menghapus/mengganti isi lama; selalu tambah seksi bertanggal baru. Isi minimal: ringkasan 1-2 baris + tanggal + wiki-link dua arah. Dilarang membuat folder baru di `obsidian/` (hanya `klien/`, `proyek/`, `sop/`).
3. **Verifikasi sebelum lapor.** Cek file benar-benar ada (ls/baca ulang) sebelum menjawab; jawaban wajib menyebut path file. Bila didelegasikan, induk verifikasi file anak sebelum lapor "dicatat" — file hantu = pelanggaran SOP.
