# SOP Listing Copy Etsy (Marketing + Sales)

Sumber: ringkasan `engineering-technical-writer` dari [msitarzewski/agency-agents](https://github.com/msitarzewski/agency-agents) (MIT). File lengkap: `REFERENCE-technical-writer.md` — baca HANYA bila butuh struktur docs besar (API/README tidak relevan untuk Etsy; yang dipakai prinsip clarity-nya).

Kapan dipakai: menulis judul, deskripsi, FAQ, dan copy pendukung listing digital planner.

## Aturan tulis (adaptasi dari docs-as-code)

1. **Second person + aktif**: "Kamu dapat 30 template siap pakai" bukan "Template disediakan".
2. **1 seksi = 1 konsep**. Jangan campur instalasi (cara download), penggunaan (cara isi planner), dan lisensi dalam satu paragraf panjang.
3. **Setiap instruksi harus jalan**: langkah "download → buka di GoodNotes/Notability → isi" WAJIB akurat per aplikasi. Salah langkah = komplain + refund.
4. **5-second test judul listing**: pembeli paham apa produknya, untuk siapa, format apa dalam 5 detik.
5. **Potong tanpa ampun**: kalimat yang tidak membantu pembeli memutuskan = hapus.

## Struktur deskripsi listing Etsy

```markdown
[Nama produk — 1 kalimat value utama]

APA YANG KAMU DAPAT
- [Isi 1 — jumlah halaman/format]
- [Isi 2]
- [Bonus jika ada]

UNTUK SIAPA
- [Persona 1: content creator yang posting rutin]
- [Persona 2]

CARA PAKAI (langkah akurat per platform)
1. Beli → file langsung bisa diunduh
2. Buka di [GoodNotes / Notability / print A4]
3. [Langkah isi]

FAQ
- Format file? PDF + [hyperlink/no]
- Refund? [kebijakan digital goods]
- [2-3 pertanyaan yang sering ditanya pembeli]

© [Tahun] [Nama toko] — lisensi personal, jangan diperjualbelikan ulang.
```
